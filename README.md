# Mourrynes Pasa | Portfolio

Personal portfolio of Mourrynes Pasa, an Information Systems graduate (S.Kom) working across web development, data analysis, and IT support.

**Live site:** https://morys-new.github.io/My_Portofolio/

## What is inside
- **Web Developer:** morika.id (multi-company accounting system), AI and automation projects, Puskesmas patient system, browser games
- **Data Analyst:** finance & tax dashboard for a 33-store retail company, coal production forecasting, Excel tools for finance
- **IT Support:** work experience and internships

## Tech stack
HTML, CSS, and vanilla JavaScript, with Three.js for the animated hero. Hosted on GitHub Pages.

## Project structure
```
index.html              main page
css/style.css           styling
js/projects-data.js     all portfolio content (projects, experience, skills)
js/main.js              rendering and interactions
assets/                 profile photo and screenshots
projects/               live demos (Puskesmas, Kisah Kampung, Metal Warfare) and PDF previews
```

To update the content, edit `js/projects-data.js`.
